2021년

## 프로젝트 소개
골프장 및 주변 편의시설 정보를 지도 기반으로 제공하기 위한 골프 정보 플랫폼.

골프장, 코스, 홀, 클럽하우스 등의 정보를 관리하고 각각의 위치 및 영역 정보를 공간 데이터로 저장하여 지도 서비스에서 활용할 수 있도록 백엔드 시스템을 구축하였다.

골프장 위치를 기반으로 지역 정보를 연결하고 골프장 및 지역별 날씨 정보를 외부 데이터와 연동하여 주기적으로 갱신하는 기능을 구현하였다.

다수 사용자의 동시 접속 및 서비스 트래픽을 고려하여 여러 대의 애플리케이션 서버를 로드밸런싱하는 운영 환경으로 구성하였으며, 실제 서비스 운영 과정에서 다수 사용자가 접속하는 환경을 경험하였다.

사용자 서비스뿐 아니라 골프장·편의시설·리뷰·회원·포인트·통계·태그·신고 등의 운영 기능과 관리자 기능을 제공하는 API 서버를 개발하였다.

## 프로젝트 내 역할
프로젝트의 백엔드 전체 개발과 백엔드 서버 운영 환경 구성을 담당하였다.

ASP.NET Core와 MSSQL을 기반으로 서비스 API 및 데이터베이스 연동 구조를 구축하고, 골프장·코스·홀·편의시설·회원·리뷰·포인트·통계 등 서비스 전반의 서버 기능을 개발하였다.

NetTopologySuite와 GeoJSON을 이용하여 골프장 및 시설의 Point·Polygon 공간정보를 처리하고, 실제 좌표와 행정구역 데이터를 연계하는 위치 기반 데이터 처리 기능을 구현하였다.

외부 날씨 데이터를 골프장 및 지역 위치와 연계하여 서비스 데이터로 가공하고, Quartz.NET Scheduler를 이용해 주기적으로 자동 갱신하는 백그라운드 처리 구조를 구축하였다.

또한 서비스 오픈 시 다수 사용자의 접속을 고려하여 본사에서 제공한 로드밸런싱 인프라를 기반으로 복수 애플리케이션 서버의 운영 환경을 직접 구성하였다. 실제 서비스 운영 과정에서 다수 사용자가 접속하는 환경을 경험하였다.
